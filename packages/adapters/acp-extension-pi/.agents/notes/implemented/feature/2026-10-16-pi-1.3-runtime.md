## Abstract

The adapter pins Pi 1.3.0 while preserving native execution, session identity,
explicit extension selection and ACP-owned MCP configuration. Codemode is loaded
explicitly in parent and child processes because `--no-extensions` also disables
built-in extensions. Handled prompts complete without a model settlement event;
todo snapshots and bounded nested-call metadata survive native session reloads.
This prepares an adapter release; Lody still needs a separately built, checksummed
managed runtime before installed providers receive it.

## Decision

Use the existing RPC adapter and Pi's native codemode, without another executor,
version detector, polling window or background scheduler. External runtime overrides
must implement the same 1.3 contract. Keep built-in MCP disabled so the ACP-selected
server list remains authoritative.

Pi records nested tools as metadata on the outer result, without their full output.
Replay those ids, arguments and statuses without inventing missing results. The
packaged todo extension attaches its existing snapshot to codemode results and
restores from those results as well as direct todo results. No separate store is added.
Extension work detached from the submitted prompt remains unsupported.

MCP tools declare an output schema derived from the official SDK's text/image
result contract. Their existing model-facing content and error handling remain;
codemode additionally receives a JSON-validated structured result so `image()` can
forward image blocks. Built-in MCP discovery is not enabled.

## Ablation (2026-10-17)

In a separate clone, remove one production change at a time from `e0578bf`,
rebuild, run the existing acceptance assertions, restore, rebuild and rerun.
Use the notification-delivery fix in `e6fb231` throughout; no assertion is removed
or weakened. The oracle is the real official CLI with the deterministic local
model in both tool modes, except the existing handled-input wire test.

| Removal                                                                  | Observed result                                                                                                                         | Decision                                               |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Parent / child explicit codemode loading (two experiments)               | Each exposes ordinary tools instead of only codemode in its process.                                                                    | Restore both.                                          |
| Handled-input settlement branch                                          | The existing no-model command / next-input test times out.                                                                              | Restore.                                               |
| Native nested-call replay                                                | Reload no longer reports the nested MCP failure.                                                                                        | Restore.                                               |
| Outer todo persistence / native restore / ACP replay (three experiments) | Each independently loses the checklist on load or resume.                                                                               | Restore all three.                                     |
| MCP output schema / structured result (two experiments)                  | Each loses the current MCP image before the model in only mode; ordinary mode passes.                                                   | Restore both.                                          |
| Unused `nestedCalls.complete` schema field                               | Both modes pass with and without it. No replay code reads the field.                                                                    | Delete the field requirement.                          |
| MCP JSON result validation                                               | Removing `z.json().parse` fails TypeScript: the SDK's unknown-valued record does not satisfy Pi's `JsonValue`. Runtime was not reached. | Restore the checked conversion rather than add a cast. |

All eleven restored controls pass. The final reduced implementation passes
`pnpm check` (69 passed, one Windows-only skip), build and both smoke modes on
macOS Node 24. No behavioral tests were deleted. Mutation patches, raw failures
and restoration logs remain local, including the initial notification-race failure.
This is a CLI/wire ablation, not another Electron or commercial-model run; the
earlier desktop acceptance and its host-image limit remain separately scoped.
